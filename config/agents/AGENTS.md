# Global Agent Instructions

## SSH Hosts

### Personal

- `ssh homeassistant` connects to the Home Assistant host as `root`.
- `ssh ocmax` connects to the ocmax host as `psoland`.
- `ssh mujo` connects to the mujo host as `psoland`.
- `ssh spark` connects to the spark host as `psoland`.

### Work

- `ssh aiservices` connects as `aiservices` to the company NVIDIA DGX Spark. It is the model-serving host and controller for a two-Spark cluster with the personal Spark as its worker.
